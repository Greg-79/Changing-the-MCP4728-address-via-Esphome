# Изменение i2c адреса MCP4728 из Esphome

Проект позволяет читать и изменять I2C‑адрес микросхемы ЦАП MCP4728 через веб‑интерфейс ESPHome или Home Assistant.  
Разработан для платформы ESP32 под фреймворк Arduino. 
## 🎯 Назначение

- Чтение текущего адреса устройства (0x60…0x67).
- Запись нового адреса (0x60…0x67) без необходимости знать текущий адрес – он определяется автоматически.
- Отображение текущего адреса в текстовом сенсоре.
- Удобный ввод целевого адреса через поле `number` в веб‑интерфейсе.
Если в вашем проекте используется несколько микросхем MCP4728, то первую из них можно оставить с заводским адресом 0х60, остальным микросхемам можно присваивать адреса поочередно. Выбор микросхемы для программирования определяется подключаемым внешним сигналом LDAC. Это позволяет изменять адрес устройства на монтажной плате не выпаивая ее. Таким образом, подключая LDAC поочередно к каждой микросхеме мы можем изменять ее адрес. 
## 🔧 Принцип работы

- Для I2C‑обмена используется **программный I2C** (класс `SoftI2cMaster`), который работает на любых GPIO.
- Чтение адреса выполняется по команде `General Call Read Address` (0x00 + 0x0C) с управлением пином LDAC.
- Запись нового адреса производится по команде `Write Address Bits` (последовательность из 4 байтов).
- Функция `readAddress()` корректно извлекает адрес из сырого байта (`(raw >> 1) & 0x07`).

## 📦 Содержимое репозитория

| Файл | Описание |
|------|----------|
| `mcp4728_address.yaml` | Главный конфигурационный файл ESPHome. Содержит все компоненты: пины, сенсоры, number, кнопки. |
| `mcp4728_setter.h` | Заголовочный файл с реализацией программного I2C, функций чтения/записи адреса и инициализации. Файл необходимо скачать и добавить в папку (например: my_components)
```
esphome:
  name: mcp4728_address
  friendly_name: mcp4728_address
  on_boot:
    - priority: 600
      then:
        - lambda: |-
            init_i2c(${sda_pin}, ${scl_pin}, ${ldac_pin});
            // Считываем текущий адрес и публикуем в сенсор
            int current = readAddress(${ldac_pin});
            char buf[10];
            sprintf(buf, "0x%02X", 0x60 + current);
            id(current_address_sensor).publish_state(buf);
            ESP_LOGI("main", "Current address: %s", buf);
  includes:
    - my_components/mcp4728_setter.h
```

## ⚙️ Подключение (схема пинов)

По умолчанию используются пины (можно изменить в `substitutions`):

| Пин | Назначение |
|-----|------------|
| GPIO4 | SDA |
| GPIO3 | SCL |
| GPIO5 | LDAC (управление стробированием) |

Соедините согласно схеме (пример для ESP32-C3, но вы можете использовать любые свободные пины):
- `SDA` MCP4728 → GPIO4 ESP32‑C3
- `SCL` MCP4728 → GPIO3 ESP32‑C3
- `LDAC` MCP4728 → GPIO5 ESP32‑C3
- Питание VDD (3.3 В) и GND

## Настройка файла конфигурации Esphome
Все что вам требуется, это только указать GPIO для назначения выходов шины i2c и управляющий GPIO LDAC
```
substitutions:
  sda_pin: "4"
  scl_pin: "3"
  ldac_pin: "5"
```
## Как пользоваться
1. Скомпилируйте и загрузите на устройство.
2. Откройте через web-интерфейс или через Home assistant
<img width="1782" height="424" alt="image" src="https://github.com/user-attachments/assets/71fa2af9-812e-4046-9209-b6568d9b2cd9" />
При открытии страницы шина автоматически прочитает и найдет устройство с текущим адресом, который отобразится в строке "Текущий адрес MCP4728". По умолчании адрес 0x60.
Для смены адреса в поле "Введите адрес в виде 0x6X" (где Х от 0 до 7) установите нужный адрес, например 0х61 и нажмите кнопку PRESS "Запись адреса MCP4728". Произойдет запись нового адреса и в логах отобразится весь процесс.

<img width="2344" height="572" alt="image" src="https://github.com/user-attachments/assets/7bd32580-3722-484f-82b2-d1a5f6bfadb3" />

При необходимости, вы можете прочитать адрес вручную, нажав кнопку PRESS "Чтение адреса".

<img width="2340" height="642" alt="image" src="https://github.com/user-attachments/assets/78db40d8-7f41-49f1-87c2-fec811247928" />

Выполнив изменение адреса первой MCP4728, вы можете перейти к изменению адреса следующих. Для этого вам необходимо подключить управляющий сигнал с LDAC к следующей микросхеме согласно схеме выше. И так далее.

<img width="2383" height="775" alt="image" src="https://github.com/user-attachments/assets/522639fa-fdc2-437b-a518-59b38ca30e73" />
При проектировании и разводке печатной платы, вы можете заранее предусмотреть дополнительные контактные площадки для удобства подключения шины и LDAC или аккуратно подпаяться к указанным контактам.
